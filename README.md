# Forth Playground

Forth를 공부하며 만든 작은 프로그램과 실험들을 모아두는 개인 저장소입니다.

## 소개

오래된 프로그래밍 언어와 독특한 프로그래밍 방식에 대한 호기심으로 Forth를 취미 삼아 공부하고 있습니다.

이 저장소는 Forth를 학습하면서 작성한 다양한 프로그램과 실험적인 코드들을 기록하기 위한 공간입니다.

특별한 목표나 실용적인 목적보다는 새로운 개념을 탐구하고, 직접 구현해 보는 과정 자체를 즐기는 데 의미를 두고 있습니다.

## 개발 환경

- **언어:** Forth
- **구현체:** Gforth

## 저장소 구성

Forth를 학습하면서 만든 여러 프로그램과 실험들을 하나의 저장소에서 관리합니다.

기본적인 스택 연산부터 다양한 알고리즘과 프로그램 구현까지, 관심이 생기는 주제를 자유롭게 다룰 예정입니다.

## 참고

이 저장소는 순수한 취미 및 학습 목적으로 운영됩니다.

일부 코드는 미완성이거나 비효율적일 수 있으며, 실제 사용보다는 실험과 학습에 중점을 두고 있습니다.
